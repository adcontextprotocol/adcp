Draft

trust.json

One file at /.well-known/trust.json that says which agents your organization runs, which keys they sign with, and who may act on your behalf.

Read the draft Join the discussion

What it answers

Which agents are ours?

agents[]: each agent's URL, roles, and signing keys, published from your own domain.

Who may act for us?

grants[]: authority you delegate to other organizations, scoped and time-boxed. Grants never carry keys.

Whose grants do we accept?

acknowledgements[]: a pointer to a grant someone else published. The terms stay in their file.

Not just for advertising

The core is protocol-neutral. Roles and scopes are namespaced, for example adcp:sales for the Ad Context Protocol, so any agent protocol can define its own profile.

A minimal example

{
  "agents": [
    {
      "url": "https://agents.acme.example/sales",
      "roles": ["adcp:sales"],
      "jwks_uri": "https://agents.acme.example/.well-known/jwks.json"
    }
  ]
}

Status

trust.json is a draft under discussion in RFC #7809. Field names may change before v1. Identity stays in brand.json.
