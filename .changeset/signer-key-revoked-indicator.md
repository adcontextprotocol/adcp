Add the experimental media-buy indicator `signer_key_revoked` (feature id `media_buy.signer_key_revoked`, `x-added-in: "3.3.0"`) and the optional `control_media_buy` `reaffirm_signer: true`, so a buyer whose key was compromised finds the buys a seller accepted under suspect requests the same way at every seller. A seller that advertises the type in `media_buy.supported_indicator_types` sets it on every buy whose creation or any accepted change came from a request verified under a `keyCompromise` key and received at or after the key's `invalidity_date` (or at any time when no date is published); buyers find those buys through `get_media_buys` `indicator_types` and the `indicators.changed` webhook. `reaffirm_signer` is accepted only from a request under a non-revoked key, changes nothing else, clears the indicator, and is listed in `available_actions[]` while the indicator is present; unintended buys use the existing `paused` and `canceled` controls. Retaining the `verified_signer` (keyid, agent, time) per buy stays a SHOULD. Bulk resolution is a 3.4 follow-up. Implements WG Session C items 1 and 2 of #8158 (R9 in `specs/agent-identity-3-3.md`).
