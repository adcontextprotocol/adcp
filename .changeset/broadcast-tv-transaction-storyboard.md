Refresh the `sales-broadcast-tv` compliance specialism (`sales_broadcast_tv` 1.1.0) so a passing run certifies one intentional, authorized TV transaction under agreed terms. The storyboard drops the "unit-based, not impression-based" framing, which predated `by_spot` and contradicted CPM-on-demo selling, and now walks five parts: discovery of `linear_tv` products with :15/:30 `video_hosted` formats, `cpm` pricing, a guaranteed forecast on a named demographic and `measurement_source`, and Live/C3/C7 windows; `TERMS_REJECTED` negotiation of `measurement_terms.billing_measurement` (currency vendor, window, variance); an authorized `create_media_buy` (signed by the runner where the seller declares `request_signing`); Live then C7 delivery reads; and reconciliation on the guarantee-basis window with `is_final` and `finalized_at`, plus `measurement_source` as an advisory check. Audience rows are read separately from as-run airing evidence.

Plan-to-as-run spot evidence (`by_spot` `scheduled` to `aired`, break position) is a new optional phase gated on the seller listing the experimental `media_buy.spot_lifecycle` feature in `experimental_features`, so today's conformant sellers are not failed and skip it as not applicable. The phase seeds its own spot-reporting product and buys it separately, because spot declarations are per product and cannot gate a runner step. Preemption cannot be provoked from the buyer side, so `preempted` and `makegood` rows are checked against the response schema when returned but are not required.

The storyboard's controller-seeded fixtures change: products are now CPM-priced with a guaranteed forecast and measurement windows, and the buy no longer assigns creatives before `sync_creatives`. Sellers that implement `seed_product` and `seed_pricing_option` need no code change; sellers that pinned the previous `flat_rate` fixtures should expect the new ones. Delivery-window webhook grading is unchanged except that it now runs last, so a missing webhook no longer cascades into the delivery and reconciliation steps.
