Add experimental forward-only media-buy lineage so a renewal, replacement, migration, or sunset can name the buy it succeeds (#5849). `create_media_buy`, `buy_products`, and `accept_proposal` (when acceptance creates a new MediaBuy) take optional `predecessor_media_buy_id` (`x-entity: media_buy`) and `lineage_reason`, a new closed enum `enums/media-buy-lineage-reason.json` (`renewal`, `terms_change`, `migration`, `sunset`, `replacement`; anything else goes in `ext`). `replacement` is the seller substituting a buy for one it could not fulfill as booked, and it is the buy-level counterpart of the spot-level `replaces_spot_id`. The two fields are supplied together or not at all. `get_media_buys` echoes both on each buy created with them (also on `core/media-buy.json`) and gains a `predecessor_media_buy_id` request filter that returns a buy's direct successors in every status (like `media_buy_ids`, it suppresses the implicit `["active"]` status default). The link is set once at creation, nothing is written back to the predecessor, and its AdCP-visible state does not change, so canceled and completed buys are never mutated. It is same seller and same account only: the predecessor MUST be an existing buy the caller can access in the request's account, otherwise the seller rejects with `MEDIA_BUY_NOT_FOUND` (with `INVALID_REQUEST` for an unpaired field or a link on a `media_buy_update` or `media_buy_cancellation` acceptance, and with `UNSUPPORTED_FEATURE` when the seller cannot record the link, so it never creates an unlinked buy silently). Because the link names an already-existing buy and is never edited, a cycle cannot form, so there is no depth limit and no new error code. Experimental (`x-status: experimental`, `x-added-in: 3.3.0`): sellers that implement it list `media_buy.lineage` in `experimental_features`. One production adopter has run equivalent lineage operations, and IAB AAMP seller-agent 2.0 is prior art, not convergence evidence. Additive and non-breaking: requests and responses without the fields are unchanged. New normative section "Media Buy Lineage" in the media-buy specification.
