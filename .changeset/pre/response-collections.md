Return full collection objects in product and proposal responses on request (experimental, feature id `media_buy.collection_cards`). The `get_products`, `list_products`, `request_proposals` and `refine_proposals` requests gain an optional `include_collections` boolean (default `false`), and their responses gain an optional top-level `collections` array of `core/response-collection.json` entries (a collection with `publisher_domain` required). Sellers return the array only when the request set `include_collections: true`. Entries cover only collections the returned products reference, one per `(publisher_domain, collection_id)`, and appear only alongside `products`. A duplicated key makes that collection unresolvable from the response, and buyers ignore entries that no product references. Copies are never authorization evidence. A copy wins over `adagents.json` only on `images`, `sample_content`, `url`, `description`, `season` and `cadence`; every other field stays anchored to `adagents.json`. A copy for a collection the publisher doesn't declare, or from an agent it doesn't authorize, is unverified display data and never feeds carriage verification. `include_collections` joins the `wholesale_feed_version` and `feed_version` scope for both `public` and `account` caches: without the flag the version ignores collection copies, with it the version also changes when any returned copy changes, and a token from the other setting is a mismatch. Adds `url` (`https://` only) to `core/collection.json`, and excludes `images`, `sample_content` and `url` from the unreleased `publisher_collection` definition-pin projection, so a new thumbnail is not pin drift. Under a new experimental feature id `brand.collection_links`, adds a `collections` field and `fields` value on `get_brand_identity` (each link requires `publisher_domain`, `collection_id` and `name`), and `publisher_domain` on `brand.json` collection links. A buyer can then go from a talent's `brand_ref` to the person's channels and confirm the link from both sides. Refs #8137.
