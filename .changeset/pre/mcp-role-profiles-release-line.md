The generated MCP role profiles now follow the package's release line. A media-buy tool introduced in a later minor joins the media-buy role catalog once the package enters that line, so `list_proposals` appears in the 3.3 media-buy profile. The profile manifests' `compatibility_scope` and `delivery` labels name the active line (for example `active-3.3-only`) instead of a fixed 3.2.
