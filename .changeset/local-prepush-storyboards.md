Make local pre-push storyboard runs faster; CI is unchanged. The pre-push hook runs the current-source and 3.0 compatibility storyboard matrices from one queue sized to the machine's cores and memory (`ADCP_STORYBOARD_JOBS` overrides it), runs isolated `/sales` and `/creative-builder` storyboards 12 to a worker process (`STORYBOARD_STORYBOARDS_PER_PROCESS=1` restores one per process), and keeps every tenant log under `test-results/storyboards/<floor set>/<tenant>.log` (`ADCP_STORYBOARD_LOG_DIR` moves it). Each storyboard process loads one @adcp/sdk build, local storyboard processes share the SDK's on-disk validator cache (`ADCP_VALIDATOR_CACHE_DIR`; an empty value turns it off), the pre-push hook shares Node's compile cache, and the schema and compliance builds skip unchanged inputs and read each source once, with byte-identical output. Grading, floors and per-storyboard results are unchanged. CI's storyboard jobs keep one storyboard per process and set no validator cache.
