A logical creative can arrive before its destination is known. It may carry several equivalent trafficking representations—for example, inline display markup plus an Internal Redirect pair, or VAST 2.0, 3.0, and 4.0 URLs. Preserve those alternatives in a `CreativeSource`, then resolve exactly one into an ordinary seller-bound creative manifest.

This is not creative rotation or A/B testing. Every entry represents the same creative content through a different delivery contract.

## Pre-binding source object

`variant_semantics` is always `one_of`. Arrays inside a manifest asset slot still mean repeatable cardinality; they do not mean delivery alternatives.

```json
{
  "$schema": "https://adcontextprotocol.org/schemas/latest/core/creative-source.json",
  "creative_id": "cr_launch_mrec",
  "revision_id": "rev_2026_08_22_1",
  "name": "Launch medium rectangle",
  "variant_semantics": "one_of",
  "delivery_variants": [
    {
      "variant_id": "source-iframe-js",
      "format_kind": "display_tag",
      "assets": {
        "serving_tag": {
          "asset_type": "display_tag",
          "delivery_type": "inline_markup",
          "markup_type": "iframe_javascript",
          "markup": "<iframe src=\"https://ads.acme-example.com/render?cb=%%CACHEBUSTER%%\"></iframe>"
        }
      },
      "source": {
        "system": "acme_ad_server",
        "source_variant": "iframe/JavaScript"
      }
    },
    {
      "variant_id": "source-internal-redirect",
      "format_kind": "display_tag",
      "assets": {
        "serving_tag": {
          "asset_type": "display_tag",
          "delivery_type": "paired_redirect",
          "ad_request_url": "https://ads.acme-example.com/ad?slot=42&cb=%%CACHEBUSTER%%",
          "clickthrough_url": "https://click.acme-example.com/redirect?dest=%%DEST_URL_ESC%%"
        }
      },
      "source": {
        "system": "acme_ad_server",
        "source_variant": "Internal Redirect"
      }
    }
  ]
}
```

`creative_id` and `revision_id` identify the logical source. Each `variant_id` is stable and unique within that source revision. Ingestion stores every valid entry without invoking URLs, executing markup, resolving macros, or discarding an unsupported representation.

## Deterministic resolution

Resolution follows this order:

1. Discover the destination's product format option and seller-wide execution capabilities.
2. Filter candidates by canonical `format_kind` and the selected `format_option_ref`.
3. Apply the option's asset shape and delivery-variant constraints.
4. For VAST, intersect product and seller version sets.
5. Evaluate every declared macro against product and seller macro capabilities.
6. Select exactly one compatible representation.

The buyer normally performs selection. A seller or creative agent may select only when it advertises `creative.delivery_variant_resolution.supported: true` and the chosen strategy; silent guessing is never allowed.

Resolution requires explicit compatibility inputs. In particular, every `video_vast` source variant has an exact asset `vast_version`, while the selected product option and seller advertise non-empty plural `vast_versions`. An absent set is unproven and cannot be treated as accepting every version on this opt-in resolution path.

Pass a source object to `build_creative` with the destination capability:

```json
{
  "$schema": "https://adcontextprotocol.org/schemas/v3/media-buy/build-creative-request.json",
  "idempotency_key": "resolve-cr-launch-mrec-rev-1",
  "creative_source": {
    "creative_id": "cr_launch_mrec",
    "revision_id": "rev_2026_08_22_1",
    "name": "Launch medium rectangle",
    "variant_semantics": "one_of",
    "delivery_variants": [
      {
        "variant_id": "source-internal-redirect",
        "format_kind": "display_tag",
        "assets": {
          "serving_tag": {
            "asset_type": "display_tag",
            "delivery_type": "paired_redirect",
            "ad_request_url": "https://ads.acme-example.com/ad?slot=42",
            "clickthrough_url": "https://click.acme-example.com/redirect"
          }
        },
        "source": { "system": "acme_ad_server", "source_variant": "Internal Redirect" }
      }
    ]
  },
  "target_capability_id": "acme_internal_redirect_300x250"
}
```

The output is the normal seller-bound manifest. `delivery_variant_selection` carries source lineage through `sync_creatives` and readback:

```json
{
  "$schema": "https://adcontextprotocol.org/schemas/v3/core/creative-manifest.json",
  "format_kind": "display_tag",
  "format_option_ref": {
    "scope": "product",
    "format_option_id": "acme_internal_redirect_300x250"
  },
  "delivery_variant_selection": {
    "source_creative_id": "cr_launch_mrec",
    "source_revision_id": "rev_2026_08_22_1",
    "selected_variant_id": "source-internal-redirect",
    "resolved_by": "buyer"
  },
  "assets": {
    "serving_tag": {
      "asset_type": "display_tag",
      "delivery_type": "paired_redirect",
      "ad_request_url": "https://ads.acme-example.com/ad?slot=42",
      "clickthrough_url": "https://click.acme-example.com/redirect"
    }
  }
}
```

The paired redirect stays one asset. A receiver cannot combine its ad-request URL with another row's click-through URL or update either half independently.

## Resolution failure

<!-- Unreleased 3.2 schema: use /schemas/latest until publication. -->
When no candidate works, return `CREATIVE_DELIVERY_VARIANT_UNRESOLVED`. `error.details` MUST conform to [`error-details/creative-delivery-variant-unresolved.json`](https://adcontextprotocol.org/schemas/latest/error-details/creative-delivery-variant-unresolved.json), with exactly one `delivery_variant_rejections` entry for every candidate. Unsupported variants remain stored in the source; failure does not delete or rewrite them.

```json
{
  "code": "CREATIVE_DELIVERY_VARIANT_UNRESOLVED",
  "message": "No source representation is compatible with the selected format option",
  "recovery": "correctable",
  "details": {
    "delivery_variant_rejections": [
      {
        "variant_id": "source-vast-2",
        "code": "vast_version_mismatch",
        "message": "VAST 2.0 is outside the product and seller compatibility intersection"
      },
      {
        "variant_id": "source-vast-4",
        "code": "macro_unsupported",
        "message": "A required player-owned macro is not supported on this execution path"
      }
    ]
  }
}
```

## VAST source alternatives

One VAST asset declares one exact `vast_version`; a product option and seller declare accepted sets.

```json
{
  "$schema": "https://adcontextprotocol.org/schemas/latest/core/creative-source.json",
  "creative_id": "cr_launch_video",
  "revision_id": "rev_7",
  "name": "Launch pre-roll",
  "variant_semantics": "one_of",
  "delivery_variants": [
    {
      "variant_id": "source-vast-2",
      "format_kind": "video_vast",
      "assets": {
        "vast_tag": {
          "asset_type": "vast",
          "delivery_type": "url",
          "url": "https://video.acme-example.com/vast/2",
          "vast_version": "2.0"
        }
      },
      "source": { "system": "acme_ad_server", "source_variant": "VAST 2.0 pre-fetch" }
    },
    {
      "variant_id": "source-vast-3",
      "format_kind": "video_vast",
      "assets": {
        "vast_tag": {
          "asset_type": "vast",
          "delivery_type": "url",
          "url": "https://video.acme-example.com/vast/3",
          "vast_version": "3.0"
        }
      },
      "source": { "system": "acme_ad_server", "source_variant": "VAST 3.0 pre-fetch" }
    },
    {
      "variant_id": "source-vast-4",
      "format_kind": "video_vast",
      "assets": {
        "vast_tag": {
          "asset_type": "vast",
          "delivery_type": "url",
          "url": "https://video.acme-example.com/vast/4",
          "vast_version": "4.0"
        }
      },
      "source": { "system": "acme_ad_server", "source_variant": "VAST 4.0 pre-fetch" }
    }
  ]
}
```

If the seller-wide ceiling is `['3.0', '4.0', '4.1', '4.2']` but the selected product accepts only `['3.0', '4.0']`, the compatible source set contains VAST 3.0 and 4.0. A highest-compatible policy may choose 4.0 only after that intersection is computed. It must never relabel the VAST 3.0 asset as 4.0.

## Variant namespaces

`CreativeSource.delivery_variants[].variant_id` identifies an equivalent source representation. It is distinct from:

- `build_variant_id`, a generated or transformed output leaf;
- `locale_variant_id`, a buyer-authored localized asset set;
- assignment weight or rotation groups; and
- delivery `variant_id`, a seller-assigned served execution.

Do not reuse values across these namespaces as a shortcut. Preserve the explicit `delivery_variant_selection` join instead.
